# 1

这是一个 Git 仓库，已推送到 GitHub。

- 远端地址：https://github.com/gulugulu-7/1.git
- 默认分支：`main`

## 使用

```bash
git status          # 查看当前改动
git add .           # 暂存改动
git commit -m "..." # 提交
git push            # 推送到 GitHub
```

## 说明

仓库初始化时目录为空，因此初始提交仅包含 `README.md` 和 `.gitignore`。
后续把你的实际文件放进这个目录，`git add .` 提交并推送即可。
